# 单片机与微机原理 · 极速刷题宝 🚀

基于 **React 18 + Vite + shadcn/ui + Lucide 图标库 (https://lucide.dev/)** 打造的现代化、沉浸式刷题与备考系统。全题库包含 **320 道题目**，覆盖单选题、填空题、判断题、简答题与程序综合题，提供详尽的标准答案、考点解析与 C51 源码。

---

## 🌟 核心技术与架构特色

- **React 18 + Vite + TypeScript**：现代前端框架驱动，毫秒级响应，组件化架构清晰规范。
- **shadcn/ui 设计系统**：遵循 shadcn/ui 官方规范的 Zinc 配色、Radix UI 交互组件、卡片与抽屉设计。
- **Lucide 图标库 (lucide-react)**：全站采用 [Lucide](https://lucide.dev/) 矢量图标，精美细腻。
- **App Shell 固定视口布局（彻底杜绝跳动）**：
  - 采用固定视口架构，翻页/切题时外层页面零跳动、零突兀上下位移；
  - 卡片内部自适应横向滑入动画（`slide-in-right` / `slide-in-left`），刷题如翻闪卡般丝滑；
  - 长题干或复杂代码卡片内部独立滚动，顶部导航与底部操作栏始终稳定吸顶/吸底。
- **手机触屏专项优化**：
  - 手机底部专属 5 键拇指操作栏（上一题、看解析、答题卡、收藏、下一题），按钮高度统一 48px；
  - 手机顶栏精简为「背题/自测 + 筛选 · 搜索 · 更多」，题型、考点、错题本、收藏夹、主题等收进底部抽屉，首屏可视内容提升约 80px；
  - 支持**左右滑动手势切题**（向左滑下一题，向右滑上一题）；
  - 自动适配 iPhone / Android 底部安全区（`safe-area-inset-bottom`）；
  - 触感震动反馈（Haptic Vibration）与 Web Audio 细腻音效。

## 🚀 两种高效模式自由切换

1. **背题速记模式（考前冲刺最推荐）**：
   - 答案与考点解析直接展示，核心关键词高亮标记。
   - 双手不离键盘，一路按 **空格键 (Space)** 或 **右方向键 (→)**，几分钟快速过完几百题，极大提高复习效率。
2. **做题自测模式**：
   - 独立作答，单选/判断支持键盘快捷键秒选。
   - 选后即刻反馈正误并显示详细解析，做错自动归档至**错题本**。
   - 支持**自动跳题开关**（答对后 360ms 无感自动滑入下一题）。
3. **错题本集中攻坚**：靶向消灭做错题目，消灭后自动清空。
4. **重点收藏**：随手收藏高频考点，考前重点复盘。
5. **320 题答题卡抽屉 (Sheet)**：全局状态网格，随时直达任意题号。
6. **全局 ⌘K 搜题 (Command Palette)**：模糊检索 8086、SCON、波特率、中断等考点，回车秒开。
7. **一键重新做题**：顶栏「重新做题」按钮（手机端在答题卡抽屉底部）可清空答题记录、错题本与正确率统计，自动回到第 1 题重新开始；弹窗会先展示待清空的数据，并支持**选择性保留收藏**。
8. **AI 深度解析（DeepSeek）**：题目卡片底部一键调用 DeepSeek API，流式生成「结论 · 考点 · 思路 · 逐项拆解 · 易错 · 口诀」六段式解析；支持 deepseek-chat / deepseek-reasoner，Key 仅保存在本机浏览器。

## 🤖 AI 深度解析（DeepSeek）

题目卡片底部的 **「AI 深度解析」** 会调用 DeepSeek 的 Chat Completions API，逐项讲清考点与解题路径，内容以 Markdown 流式输出，并按题缓存。桌面端顶栏的 ✨ 图标可随时打开设置。

**配置方式**

1. 点击「AI 深度解析」→ 未配置时会自动弹出设置；也可从面板底部的「设置」或顶栏 ✨ 进入；
2. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建 API Key，粘贴到设置里；
3. Base URL 默认 `https://api.deepseek.com/v1`，一般无需修改；如使用中转可自行填写，程序会自动补全 `/chat/completions`；
4. 选择模型：`deepseek-chat`（响应快）或 `deepseek-reasoner`（推理更强）；
5. 点击「测试连接」确认可用后保存。

**隐私与网络**

- API Key 与解析缓存**只保存在本机浏览器 localStorage**，不会上传到本站；
- 请求由浏览器直接发往 `api.deepseek.com`（官方接口支持 CORS），不经过本站服务器；
- 若所在网络无法直连 DeepSeek，可把 Base URL 换成可访问的中转地址；
- 解析结果按题缓存，可在设置里一键清空。

## ⌨️ 极速全键盘操作指南

| 按键 | 功能说明 |
| :--- | :--- |
| **`A` / `B` / `C` / `D`** 或 **`1` / `2` / `3` / `4`** | 单选题快速选择选项 |

| **`→` (右箭头)** 或 **`K`** | 下一题 |
| **`←` (左箭头)** 或 **`J`** | 上一题 |
| **`S`** | 收藏 / 取消收藏本题（星标） |
| **`R`** | 重做本题（重置当前题答题记录） |
| **`M`** | 快速切换【背题速记】与【做题自测】模式 |
| **`⌘K` / `Ctrl+K`** | 唤起全局考点搜索弹窗 |
| **`Esc`** | 关闭答题卡抽屉、搜索弹窗或重新做题确认弹窗 |

## 🖥️ 快速运行与启动方式

### 方式 1：双击一键运行（推荐，免配置）
直接双击根目录下的 **`启动刷题网站.command`**：
- 自动启动服务并打开系统默认浏览器；
- 终端会展示**手机局域网网址**（如 `http://192.168.x.x:8000`），手机与电脑连同一个 Wi-Fi 即可手机扫码或输入网址刷题！

### 方式 2：Python 本地服务
在终端运行：
```bash
python3 server.py
```
访问 `http://localhost:8000` 即可使用编译好的生产版本。

### 方式 3：React 开发模式 (Vite Dev Server)
在终端运行：
```bash
pnpm dev
# 或 npm run dev
```
打开 `http://localhost:5173` 体验极速热重载开发。

若修改代码后重新构建生产包：
```bash
pnpm build
# 或 npm run build
```
编译产物位于 `dist/` 目录。

## ⚡ 性能与加载策略

- **首屏骨架**：HTML 内联骨架与全部 CSS，HTML 到达即绘制；主题在 `<head>` 提前应用，深色模式不再闪白。
- **按需加载**：程序题语法高亮（Prism）与 AI 解析面板独立分包，只在用到时下载；主包 gzip 约 123KB（含全部 320 题题库）。
- **强缓存 + Service Worker**：`/assets/*` 一年 `immutable`；首次访问后 Service Worker 缓存静态资源，二次访问基本秒开，断网也能打开。
- **实测（Lighthouse 移动端模拟 4G）**：FCP 0.9s、LCP 1.7s、TBT 0ms、CLS 0。
- **国内访问**：Cloudflare Pages 边缘节点在境外，大陆直连通常有 200–600ms 的 RTT。若用户主要在大陆且追求更低延迟，可在完成 ICP 备案后接入国内 CDN（阿里云 / 腾讯云 EdgeOne），或使用 Cloudflare China Network；本站无需改代码。
